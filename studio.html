Studio — لوحة إدارة عبر GitHub

هذه الصفحة تتيح لك تعديل ملفات البيانات ورفع الصور مباشرة إلى نفس مستودع GitHub باستخدام GitHub API—بدون خوادم إضافية.

1) الربط مع GitHub (مرة واحدة)

أنشئ Fine-grained PAT على GitHub بحقوق Contents: Read/Write لهذا المستودع فقط. لا تشارك التوكن أبدًا.
غير متصل

2) تعديل بيانات العروض (listings.json)

3) تعديل بيانات المزادات (auctions.json)

4) رفع الصور إلى assets/img/

اختر صورًا لرفعها — سيتم رفعها إلى assets/img/ بنفس الأسماء.

لم تبدأ

5) ملاحظات الأمان

  • يُخزَّن التوكن داخل المتصفح localStorage لديك فقط. لا يُرسل لأي طرف آخر.
  • استخدم Fine-grained PAT على مستودع واحد فقط. يمكنك حذفه من GitHub في أي وقت.
  • تأكد من صحة JSON قبل الحفظ. أي خطأ سيمنع الموقع من القراءة.
